ODE 1: บทนำและสมการแยกตัวแปรได้ODE 1: Introduction & Separable Equations

อนุพันธ์คืออัตราการเปลี่ยนแปลง สมการเชิงอนุพันธ์คือสมการที่มีอนุพันธ์ของฟังก์ชันที่ไม่รู้ค่า เป้าหมายคือหาฟังก์ชันนั้น บทนี้ครอบคลุมอันดับ ระดับขั้น ผลเฉลยทั่วไป/เฉพาะ และวิธีแรกในการแก้: การแยกตัวแปร

A derivative is a rate of change; a differential equation is an equation involving derivatives of an unknown function, and the goal is to find that function. This chapter covers order, degree, general vs. particular solutions, and the first solution method: separation of variables.

1. อัตราการเปลี่ยนแปลงและอนุพันธ์ย่อย1. Rates of change & partial derivatives

ความเร็ว (m/s) คือระยะทางที่เปลี่ยนต่อเวลา: \(v = \dfrac{\Delta s}{\Delta t} \to \dfrac{ds}{dt}\) เมื่อ \(\Delta t \to 0\) — นี่คืออนุพันธ์ของ \(s(t)\) ในทำนองเดียวกัน \(\dfrac{dy}{dx}\) คืออัตราการเปลี่ยนของ \(y(x)\)

Speed (m/s) is change in distance per unit time: \(v = \dfrac{\Delta s}{\Delta t} \to \dfrac{ds}{dt}\) as \(\Delta t \to 0\) — the derivative of \(s(t)\). Likewise \(\dfrac{dy}{dx}\) is the rate of change of \(y(x)\).

ถ้าฟังก์ชันมีหลายตัวแปร เช่นความสูงบนแผนที่เส้นชั้นความสูง \(z(x, y)\) เราวัดอัตราการเปลี่ยนทีละทิศ เรียกว่า อนุพันธ์ย่อย — \(\dfrac{\partial z}{\partial x} \approx \dfrac{\Delta z}{\Delta x}\) (เดินตามแกน \(x\), \(y\) คงที่) และ \(\dfrac{\partial z}{\partial y} \approx \dfrac{\Delta z}{\Delta y}\) เช่น ถ้าเดินจากเส้นชั้น 30 ไป 50 จะได้ \(\Delta z = 50 - 30\)

For a function of several variables — like height \(z(x, y)\) on a contour map — we measure the rate in one direction at a time: the partial derivatives \(\dfrac{\partial z}{\partial x} \approx \dfrac{\Delta z}{\Delta x}\) (move along \(x\), hold \(y\) fixed) and \(\dfrac{\partial z}{\partial y} \approx \dfrac{\Delta z}{\Delta y}\). Walking from the 30 contour to the 50 contour gives \(\Delta z = 50 - 30\).

ตัวอย่าง 8.1Example 8.1\(z(x,y) = 5x^2 + 2xy + 3y^4\)
\[ \frac{\partial z}{\partial x} = 10x + 2y \quad(y = \text{const}),\qquad \frac{\partial z}{\partial y} = 2x + 12y^3 \quad(x = \text{const}) \]

เวกเตอร์ เกรเดียนต์ \(\nabla z = \left(\tfrac{\partial z}{\partial x}, \tfrac{\partial z}{\partial y}\right)\) ชี้ไปทางที่ชันขึ้นมากที่สุด (div, curl, grad เป็นเครื่องมือของแคลคูลัสเวกเตอร์ที่สร้างจากอนุพันธ์ย่อยเหล่านี้)

The gradient \(\nabla z = \left(\tfrac{\partial z}{\partial x}, \tfrac{\partial z}{\partial y}\right)\) points in the direction of steepest ascent. (Div, curl and grad are vector-calculus tools built from these partial derivatives.)

2. สมการเชิงอนุพันธ์คืออะไร2. What is a differential equation?

นิยามDefinition

สมการเชิงอนุพันธ์ (DE) คือสมการที่มีอนุพันธ์ของฟังก์ชันที่ไม่ทราบค่า เช่น \(y(x)\) ถ้ามีตัวแปรอิสระตัวเดียวเรียกว่า สมการเชิงอนุพันธ์สามัญ (ODE) การ “แก้” คือหาฟังก์ชัน \(y = f(x)\) ที่เขียนด้วย \(x\) ล้วน ๆ

A differential equation (DE) involves derivatives of an unknown function such as \(y(x)\). With a single independent variable it is an ordinary differential equation (ODE). To “solve” it means to find the function \(y = f(x)\), written in terms of \(x\) only.

\[ \text{(1)}\ \ \frac{dy}{dx} = x^2 \qquad \text{(2)}\ \ \frac{d^2y}{dx^2} + 3\frac{dy}{dx} - y = 0 \qquad \text{(3)}\ \ y'' - 3y' - 5xy = 0 \]
ระวังCareful

การย้ายข้างเป็น \(y = \dfrac{d^2y}{dx^2} + 3\dfrac{dy}{dx}\) ไม่ใช่การแก้สมการ — ด้านขวายังมี \(y\) อยู่ในรูปอนุพันธ์ ผลเฉลยต้องเป็นฟังก์ชันของ \(x\) ล้วน ๆ

Rearranging to \(y = \dfrac{d^2y}{dx^2} + 3\dfrac{dy}{dx}\) is not solving — the right side still contains \(y\) through its derivatives. A solution must be a function of \(x\) alone.

3. อันดับ (Order) และระดับขั้น (Degree)3. Order & degree

อันดับOrder

อนุพันธ์ครั้งที่สูงที่สุดที่ปรากฏในสมการ

The highest derivative that appears.

ระดับขั้นDegree

เลขยกกำลังของอนุพันธ์อันดับสูงสุดนั้น

The power of that highest-order derivative.

4. ผลเฉลยทั่วไปและผลเฉลยเฉพาะ4. General vs particular solutions

  • ผลเฉลยทั่วไป (General Solution, GS) — มีค่าคงที่ \(C\) ใด ๆ (เป็นตระกูลของเส้นโค้ง)General solution (GS) — contains an arbitrary constant \(C\) (a family of curves).
  • ผลเฉลยเฉพาะ (Particular Solution, PS) — หา \(C\) ได้จากเงื่อนไขเริ่มต้น เช่น \(y(0) = 4\)Particular solution (PS) — \(C\) is fixed by an initial condition such as \(y(0) = 4\).
ตัวอย่าง 8.2Example 8.2\(\dfrac{dy}{dx} = 6x^2 + 1,\ \ y(0) = 4\)
\[ \int dy = \int (6x^2 + 1)\,dx \;\Rightarrow\; y + C_1 = 2x^3 + x + C_2 \;\Rightarrow\; y = 2x^3 + x + C \quad\text{(GS)} \]

(รวมค่าคงที่ \(C = C_2 - C_1\) เป็นตัวเดียว) แทน \(y(0) = 4\): \(4 = 0 + 0 + C \Rightarrow C = 4\)

(The constants merge into one, \(C = C_2 - C_1\).) Apply \(y(0) = 4\): \(4 = 0 + 0 + C \Rightarrow C = 4\).

PS\(y = 2x^3 + x + 4\)

6. สมการแยกตัวแปรได้6. Separable equations

วิธีการMethod

แยก \(x\) ไปอยู่กับ \(dx\) และ \(y\) ไปอยู่กับ \(dy\) แล้วอินทิเกรตทั้งสองข้าง:

Put every \(x\) with \(dx\) and every \(y\) with \(dy\), then integrate both sides:

\[ M(x)\,dx + N(y)\,dy = 0 \;\Longrightarrow\; \int M(x)\,dx + \int N(y)\,dy = C \]

รูปที่พบบ่อย: \(\dfrac{dy}{dx} = g(x)\,h(y) \;\Rightarrow\; \displaystyle\int \frac{dy}{h(y)} = \int g(x)\,dx\)

Common form: \(\dfrac{dy}{dx} = g(x)\,h(y) \;\Rightarrow\; \displaystyle\int \frac{dy}{h(y)} = \int g(x)\,dx\)

เครื่องมือที่ใช้บ่อยHandy tools
\[ \int \frac{f'(u)}{f(u)}\,du = \ln|f(u)| + C,\qquad \int \frac{dx}{1 + x^2} = \tan^{-1}x + C,\qquad a\ln x = \ln x^a,\qquad \ln a + \ln b = \ln ab \]

7. ตัวอย่าง7. Worked examples

ตัวอย่าง 8.3Example 8.3\(3(1 + y^2)\,dx - 5xy\,dy = 0\)

หารด้วย \(x(1+y^2)\) เพื่อแยกตัวแปร:

Divide by \(x(1+y^2)\) to separate:

\[ 3\int\frac{dx}{x} = 5\int\frac{y}{1 + y^2}\,dy \]

ด้านขวาใช้ \(d(1 + y^2) = 2y\,dy\):

On the right, use \(d(1 + y^2) = 2y\,dy\):

\[ 3\ln|x| = \frac52\int\frac{d(1+y^2)}{1+y^2} = \frac52\ln(1 + y^2) + \ln C_0 \;\Rightarrow\; \ln x^3 = \ln\!\big[C_0(1 + y^2)^{5/2}\big] \]
GS\(x^3 = C_0\,(1 + y^2)^{5/2}\)
ตัวอย่าง 8.4Example 8.4\(\dfrac{dy}{dx} = \dfrac{2y^2 - xy^2}{x^2 + 1}\)
\[ \frac{dy}{dx} = \frac{y^2(2 - x)}{x^2 + 1} \;\Rightarrow\; \int y^{-2}\,dy = \int\frac{2}{x^2+1}\,dx - \int\frac{x}{x^2+1}\,dx \]
\[ -\frac1y = 2\tan^{-1}x - \frac12\ln(x^2 + 1) + C \]
GS\(-\dfrac1y = 2\tan^{-1}x - \tfrac12\ln(x^2 + 1) + C\)
ตัวอย่าง 8.5Example 8.5\(\dfrac{dy}{dx} - y = 0,\ \ y(0) = 3\)
\[ \int\frac{dy}{y} = \int dx \;\Rightarrow\; \ln|y| = x + C \;\Rightarrow\; y = e^{x + C} = e^C e^x = C_0e^x \quad\text{(GS)} \]

แทน \(y(0) = 3\): \(3 = C_0e^0 \Rightarrow C_0 = 3\)

Apply \(y(0) = 3\): \(3 = C_0e^0 \Rightarrow C_0 = 3\).

PS\(y = 3e^x\)
ตัวอย่าง 8.6Example 8.6\((\ln y)^3\,y' = x^4y,\ \ y(2) = 1\)
\[ \int\frac{(\ln y)^3}{y}\,dy = \int x^4\,dx \]

ด้านซ้ายใช้ \(d(\ln y) = \tfrac1y\,dy\):

On the left, use \(d(\ln y) = \tfrac1y\,dy\):

\[ \int(\ln y)^3\,d(\ln y) = \frac{x^5}{5} \;\Rightarrow\; \frac14(\ln y)^4 = \frac{x^5}{5} + C \quad\text{(GS)} \]

แทน \(y(2) = 1\) (\(\ln 1 = 0\)): \(0 = \tfrac{32}{5} + C \Rightarrow C = -\tfrac{32}{5}\)

Apply \(y(2) = 1\) (\(\ln 1 = 0\)): \(0 = \tfrac{32}{5} + C \Rightarrow C = -\tfrac{32}{5}\).

PS\(\tfrac14(\ln y)^4 = \dfrac{x^5}{5} - \dfrac{32}{5}\)
ไม่ใช่ทุกสมการที่แยกตัวแปรได้Not every equation separates

\(\dfrac{dy}{dx} = \dfrac{xy}{x^2 - y^2}\) แยก \(x\) กับ \(y\) ออกจากกันไม่ได้ ต้องใช้วิธีสมการเอกพันธ์ ในบทถัดไป

\(\dfrac{dy}{dx} = \dfrac{xy}{x^2 - y^2}\) cannot be separated. It needs the homogeneous equation method of the next chapter.

ดูเฉลยShow solution
