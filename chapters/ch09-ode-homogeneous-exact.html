ODE 2: สมการเอกพันธ์และสมการแม่นตรงODE 2: Homogeneous & Exact Equations

สองวิธีสำหรับสมการที่แยกตัวแปรตรง ๆ ไม่ได้: (1) สมการเอกพันธ์ — แทน \(y = vx\) แล้วกลายเป็นสมการแยกตัวแปรได้ (2) สมการแม่นตรง — สมการที่เป็นอนุพันธ์รวมของฟังก์ชัน \(f(x, y)\) บางตัว

Two methods for equations that don’t separate directly: (1) homogeneous equations — substitute \(y = vx\) to make them separable; (2) exact equations — equations that are the total differential of some function \(f(x, y)\).

1. สมการเชิงอนุพันธ์เอกพันธ์1. Homogeneous differential equations

นิยามDefinition

ODE อันดับหนึ่งเป็นเอกพันธ์ ถ้าเขียนได้ในรูป \(\dfrac{dy}{dx} = F\!\left(\dfrac{y}{x}\right)\) — เช็กง่าย ๆ: ทุกพจน์ใน \(M(x,y)\,dx + N(x,y)\,dy = 0\) มีดีกรีรวมเท่ากัน (เช่น \(x^2, xy, y^2\) ดีกรี 2 ทั้งหมด)

A first-order ODE is homogeneous if it can be written \(\dfrac{dy}{dx} = F\!\left(\dfrac{y}{x}\right)\). Quick test: every term of \(M(x,y)\,dx + N(x,y)\,dy = 0\) has the same total degree (e.g. \(x^2, xy, y^2\) are all degree 2).

วิธีแก้: แทน \(y = vx\)Method: substitute \(y = vx\)
\[ y = vx \quad\Rightarrow\quad v = \frac yx, \qquad dy = v\,dx + x\,dv \]
  1. แทน \(y\) และ \(dy\) ลงในสมการSubstitute \(y\) and \(dy\) into the equation.
  2. ตัด \(x\) ที่เป็นตัวร่วม — สมการจะเหลือแค่ \(v\) กับ \(x\) และแยกตัวแปรได้Cancel the common powers of \(x\) — only \(v\) and \(x\) remain, and the equation is separable.
  3. อินทิเกรต แล้วแทนกลับ \(v = y/x\)Integrate, then substitute back \(v = y/x\).

2. ตัวอย่างสมการเอกพันธ์2. Homogeneous examples

ตัวอย่าง 9.1Example 9.1\(2x\,dy = (x + y)\,dx\)
\[ 2x(v\,dx + x\,dv) = (x + vx)\,dx \;\Rightarrow\; 2v\,dx + 2x\,dv = (1 + v)\,dx \;\Rightarrow\; 2x\,dv = (1 - v)\,dx \]

ได้สมการแยกตัวแปรได้:

This is separable:

\[ \int\frac{dv}{1 - v} = \int\frac{dx}{2x} \;\Rightarrow\; -\ln|1 - v| = \tfrac12\ln|x| + \ln C \;\Rightarrow\; \ln\left|\frac{1}{1-v}\right| = \ln\left|C\sqrt x\right| \;\Rightarrow\; \frac{1}{1 - v} = C\sqrt x \]

แทนกลับ \(v = y/x\): \(\dfrac{1}{1 - y/x} = \dfrac{x}{x - y} = C\sqrt x\) จัดรูปได้ \(x - y = \dfrac{\sqrt x}{C}\)

Back-substitute \(v = y/x\): \(\dfrac{1}{1 - y/x} = \dfrac{x}{x - y} = C\sqrt x\), which rearranges to \(x - y = \dfrac{\sqrt x}{C}\).

GS\(\dfrac{1}{1 - y/x} = C\sqrt x \quad\Longleftrightarrow\quad y = x - K\sqrt x\)

ตรวจ: \(y' = 1 - \tfrac{K}{2\sqrt x}\) ดังนั้น \(2xy' = 2x - K\sqrt x = x + y\) ✓

Check: \(y' = 1 - \tfrac{K}{2\sqrt x}\), so \(2xy' = 2x - K\sqrt x = x + y\) ✓

ตัวอย่าง 9.2Example 9.2\(y' = \dfrac{xy}{x^2 - y^2}\)

(สมการที่แยกตัวแปรไม่ได้จากบทที่ 8) เขียนเป็น \((x^2 - y^2)\,dy = xy\,dx\) แล้วแทน \(y = vx\):

(The non-separable equation from Chapter 8.) Write it as \((x^2 - y^2)\,dy = xy\,dx\) and substitute \(y = vx\):

\[ x^2(1 - v^2)(v\,dx + x\,dv) = vx^2\,dx \;\Rightarrow\; v\,dx - v^3\,dx + x(1 - v^2)\,dv = v\,dx \;\Rightarrow\; x(1 - v^2)\,dv = v^3\,dx \]
\[ \int\frac{dx}{x} = \int\frac{1 - v^2}{v^3}\,dv = \int v^{-3}\,dv - \int\frac{dv}{v} \;\Rightarrow\; \ln|x| = -\frac{1}{2v^2} - \ln|v| + C \]

แทน \(v = y/x\) และใช้ \(\ln|x| + \ln|y/x| = \ln|y|\):

Substitute \(v = y/x\) and use \(\ln|x| + \ln|y/x| = \ln|y|\):

\[ \ln|x| = -\frac{x^2}{2y^2} - \ln|y| + \ln|x| + C \;\Rightarrow\; \ln|y| + \frac{x^2}{2y^2} = C \]
GS\(\ln|y| + \dfrac{x^2}{2y^2} = C \quad\Longleftrightarrow\quad y = C_0\,e^{-x^2/(2y^2)}\)

หมายเหตุ: \(e^{a + C} = e^a\cdot e^C\) (ผลคูณ ไม่ใช่ผลบวก) จึงรวม \(e^C\) เป็นค่าคงที่ \(C_0\)

Note: \(e^{a + C} = e^a\cdot e^C\) (a product, not a sum), so \(e^C\) becomes the constant \(C_0\).

ตัวอย่าง 9.3Example 9.3\(y' = \dfrac{2xe^{-y/x} + y}{x},\ \ y(1) = 0\)
\[ x(v\,dx + x\,dv) = (2xe^{-v} + vx)\,dx \;\Rightarrow\; v\,dx + x\,dv = 2e^{-v}\,dx + v\,dx \;\Rightarrow\; x\,dv = 2e^{-v}\,dx \]
\[ \frac12\int e^{v}\,dv = \int\frac{dx}{x} \;\Rightarrow\; \frac12e^{v} = \ln|x| + C \;\Rightarrow\; e^{y/x} = 2\ln|x| + C \quad\text{(GS)} \]

แทน \(y(1) = 0\): \(e^0 = 2\ln 1 + C \Rightarrow C = 1\)

Apply \(y(1) = 0\): \(e^0 = 2\ln 1 + C \Rightarrow C = 1\).

PS\(e^{y/x} = 2\ln|x| + 1\)

3. อนุพันธ์รวมและกฎลูกโซ่3. Total differential & chain rule

ถ้า \(z = f(x, y)\) และทั้ง \(x, y\) ขึ้นกับ \(t\) กฎลูกโซ่ให้

If \(z = f(x, y)\) and both \(x, y\) depend on \(t\), the chain rule gives

\[ \frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt} \qquad\Longrightarrow\qquad dz = \underbrace{\frac{\partial f}{\partial x}}_{M}dx + \underbrace{\frac{\partial f}{\partial y}}_{N}dy \]

ดังนั้นสมการอันดับหนึ่ง \(M\,dx + N\,dy = 0\) อาจเป็น \(dz = 0\) ของฟังก์ชัน \(f\) บางตัว ซึ่งหมายความว่า \(f(x, y) = C\) ทันที

So a first-order equation \(M\,dx + N\,dy = 0\) may be \(dz = 0\) for some function \(f\) — which immediately means \(f(x, y) = C\).

4. สมการแม่นตรง (Exact DE)4. Exact equations

การทดสอบความแม่นตรงTest for exactness
\[ M\,dx + N\,dy = 0 \text{ is exact} \iff \frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} \]

เหตุผล: ถ้า \(M = f_x\) และ \(N = f_y\) แล้ว \(\dfrac{\partial M}{\partial y} = \dfrac{\partial^2 f}{\partial y\,\partial x}\) และ \(\dfrac{\partial N}{\partial x} = \dfrac{\partial^2 f}{\partial x\,\partial y}\) ซึ่งเท่ากันเสมอ (อนุพันธ์ย่อยผสมสลับลำดับได้)

Why: if \(M = f_x\) and \(N = f_y\), then \(\dfrac{\partial M}{\partial y} = \dfrac{\partial^2 f}{\partial y\,\partial x}\) and \(\dfrac{\partial N}{\partial x} = \dfrac{\partial^2 f}{\partial x\,\partial y}\), and mixed partials are always equal.

สมการEquation\(\partial M/\partial y\)\(\partial N/\partial x\)แม่นตรง?Exact?
\(2xy\,dx + x^2\,dy = 0\)\(2x\)\(2x\)✓
\(4x\sin y\,dx + 2x^2\cos y\,dy = 0\)\(4x\cos y\)\(4x\cos y\)✓
\(3x^2y\,dx + x^3y\,dy = 0\)\(3x^2\)\(3x^2y\)✗

(สมการแรกแยกตัวแปรได้ด้วย: \(\tfrac2x\,dx = -\tfrac1y\,dy\) — สมการหนึ่งอาจแก้ได้หลายวิธี)

(The first one is also separable: \(\tfrac2x\,dx = -\tfrac1y\,dy\). One equation can have several methods.)

วิธีแก้สมการแม่นตรงSolving an exact equation
  1. ตรวจว่า \(M_y = N_x\)Check \(M_y = N_x\).
  2. คำนวณ \(\int M\,dx\) (มอง \(y\) เป็นค่าคงที่) และ \(\int N\,dy\) (มอง \(x\) เป็นค่าคงที่)Compute \(\int M\,dx\) (holding \(y\) constant) and \(\int N\,dy\) (holding \(x\) constant).
  3. รวมพจน์ทั้งหมดที่ได้ โดยนับพจน์ที่ซ้ำกันเพียงครั้งเดียว แล้วตั้งให้เท่ากับ \(C\)Combine all terms, counting any repeated term only once, and set the result equal to \(C\).

(วิธีทางการ: \(f = \int M\,dx + g(y)\) แล้วหา \(g(y)\) จากเงื่อนไข \(f_y = N\) — ได้ผลเหมือนกัน)

(Formal version: \(f = \int M\,dx + g(y)\), then find \(g(y)\) from \(f_y = N\). Same result.)

5. ตัวอย่างสมการแม่นตรง5. Exact examples

ตัวอย่าง 9.4Example 9.4\((2x + 4y - 1)\,dx + (4x + 6y + 1)\,dy = 0\)

ตรวจ: \(\dfrac{\partial M}{\partial y} = 4 = \dfrac{\partial N}{\partial x}\) ✓ แม่นตรง

Check: \(\dfrac{\partial M}{\partial y} = 4 = \dfrac{\partial N}{\partial x}\) ✓ exact.

\[ \int M\,dx = x^2 + \boxed{4xy} - x + C_x(y), \qquad \int N\,dy = \boxed{4xy} + 3y^2 + y + C_y(x) \]

พจน์ \(4xy\) ซ้ำกัน นับครั้งเดียว:

The term \(4xy\) appears in both — count it once:

GS\(x^2 + 4xy - x + 3y^2 + y = C\)

ตรวจ: \(f_x = 2x + 4y - 1 = M\) ✓ และ \(f_y = 4x + 6y + 1 = N\) ✓

Check: \(f_x = 2x + 4y - 1 = M\) ✓ and \(f_y = 4x + 6y + 1 = N\) ✓

ตัวอย่าง 9.5Example 9.5\((4x - y)\,dx + (6y - x)\,dy = 0\)
\[ M = 4x - y \Rightarrow M_y = -1,\qquad N = 6y - x \Rightarrow N_x = -1 \quad\checkmark \]
\[ \int M\,dx = 2x^2 - xy + C_x,\qquad \int N\,dy = 3y^2 - xy + C_y \]
GS\(2x^2 - xy + 3y^2 = C\)

แก้สมการเอกพันธ์ \(\dfrac{dy}{dx} = \dfrac{x + y}{x}\)

ดูเฉลยShow solution
\[ v + xv' = 1 + v \Rightarrow v' = \tfrac1x \Rightarrow v = \ln|x| + C \Rightarrow y = x\ln|x| + Cx \]
2.

ตรวจความแม่นตรงแล้วแก้ \((2xy + 3)\,dx + (x^2 - 1)\,dy = 0\)

\[ M_y = 2x = N_x\ \checkmark;\quad \int M\,dx = x^2y + 3x,\quad \int N\,dy = x^2y - y \;\Rightarrow\; x^2y + 3x - y = C \]

Solve \(4x\sin y\,dx + 2x^2\cos y\,dy = 0\) as an exact equation.

ดูเฉลยShow solution
\[ \int 4x\sin y\,dx = 2x^2\sin y,\quad \int 2x^2\cos y\,dy = 2x^2\sin y \;\Rightarrow\; 2x^2\sin y = C \]

\((x^2 + y^2)\,dx + 2xy\,dy = 0\) เป็นสมการแบบใด? แก้สมการ

What type is \((x^2 + y^2)\,dx + 2xy\,dy = 0\)? Solve it.

ดูเฉลยShow solution

It is both homogeneous (all terms degree 2) and exact (\(M_y = 2y = N_x\)). The exact method is quicker:

\[ \int M\,dx = \tfrac{x^3}{3} + xy^2,\quad \int N\,dy = xy^2 \;\Rightarrow\; \tfrac{x^3}{3} + xy^2 = C \]
