การแปลงลาปลาซThe Laplace Transform

การแปลงลาปลาซเปลี่ยนฟังก์ชันของเวลา \(f(t)\) เป็นฟังก์ชันของ \(s\) และเปลี่ยนอนุพันธ์ให้เป็นการคูณด้วย \(s\) สมการเชิงอนุพันธ์จึงกลายเป็นสมการพีชคณิตที่แก้ง่าย แล้วแปลงกลับด้วยการแปลงลาปลาซผกผัน (เนื้อหาจากบทเรียน Laplace #1–#3)

The Laplace transform turns a function of time \(f(t)\) into a function of \(s\), and turns derivatives into multiplication by \(s\). A differential equation becomes an easy algebraic equation, which we solve and then transform back with the inverse Laplace transform. (Content from lectures Laplace #1–#3.)

1. การแปลงเป็น “กล่อง”1. Transforms as “boxes”

ทุกการแปลงที่เรียนมามีโครงเดียวกัน: ค่าขาเข้า → กล่องฟังก์ชัน → ค่าขาออก

Every transformation we have met has the same shape: input → function box → output.

ขาเข้าInputกล่องBoxขาออกOutputชื่อName
\(x\)\(y = mx + c\)\(y\)การแปลงเชิงเส้น (บทที่ 4)Linear transformation (Ch. 4)
\(x\)\(y = ax^2 + bx + c\)\(y\)การแปลงกำลังสองQuadratic transformation
\(t\)\(\displaystyle\int_{-\infty}^{\infty} f(t)\,e^{-2\pi i\nu t}\,dt\)\(\nu\)การแปลงฟูเรียร์ (บทที่ 7)Fourier transform (Ch. 7)
\(t\)\(\displaystyle\int_{0}^{\infty} e^{-st} f(t)\,dt\)\(s\)การแปลงลาปลาซLaplace transform

2. นิยามและตัวอย่างพื้นฐาน2. Definition & basic transforms

นิยามDefinition
\[ \mathcal{L}\{f(t)\} = F(s) = \int_0^{\infty} e^{-st}\,f(t)\,dt \]

อินทิกรัลถึง \(\infty\) หาค่าได้เมื่อ \(e^{-st}\) ลดลงเร็วพอ — ใช้ข้อเท็จจริงว่า \(e^{-s\cdot\infty} = \dfrac{1}{e^{\infty}} \to 0\) เมื่อ \(s > 0\)

The integral to \(\infty\) exists when \(e^{-st}\) decays fast enough. We use the fact that \(e^{-s\cdot\infty} = \dfrac{1}{e^{\infty}} \to 0\) for \(s > 0\).

ตัวอย่าง 12.1Example 12.1\(f(t) = 1\)
\[ \mathcal{L}\{1\} = \int_0^{\infty} e^{-st}\,dt = \left[-\frac1s e^{-st}\right]_{t=0}^{t=\infty} = \Big[-\tfrac1s\underbrace{e^{-s(\infty)}}_{\to\,0}\Big] - \Big[-\tfrac1s\underbrace{e^{-s(0)}}_{=\,1}\Big] = \frac1s \]
ผลลัพธ์Result\(\mathcal{L}\{1\} = \dfrac1s\)
ตัวอย่าง 12.2Example 12.2\(f(t) = e^{at}\)
\[ \mathcal{L}\{e^{at}\} = \int_0^{\infty} e^{-st}e^{at}\,dt = \int_0^{\infty} e^{(a-s)t}\,dt = \frac{1}{a - s}\Big[e^{(a-s)(\infty)} - \underbrace{e^{(a-s)(0)}}_{=\,1}\Big] \]

พิจารณาค่า \(e^{(a-s)\infty}\) สามกรณี:

Look at \(e^{(a-s)\infty}\) in three cases:

  1. \(a - s > 0\): เลขชี้กำลังเป็นบวกมาก \(e^{+\infty} \to \infty\) → อินทิกรัลลู่ออก หาค่าไม่ได้\(a - s > 0\): the exponent is hugely positive, \(e^{+\infty} \to \infty\) → the integral diverges.
  2. \(a - s < 0\): เลขชี้กำลังติดลบมาก \(e^{-\infty} = \dfrac{1}{e^{\infty}} \to 0\) ✓\(a - s < 0\): the exponent is hugely negative, \(e^{-\infty} = \dfrac{1}{e^{\infty}} \to 0\) ✓
  3. \(a - s = 0\): หารด้วย \(a - s = 0\) ไม่ได้\(a - s = 0\): we cannot divide by \(a - s = 0\).

จึงใช้ได้เฉพาะกรณีที่ 2 (\(s > a\)):

So only case 2 works (\(s > a\)):

\[ \mathcal{L}\{e^{at}\} = \frac{1}{a - s}(0 - 1) = \frac{-1}{a - s} = \frac{1}{s - a},\qquad s > a \]
ผลลัพธ์Result\(\mathcal{L}\{e^{at}\} = \dfrac{1}{s - a}\)

3. ลาปลาซของ \(\sin at\) — อินทิเกรตทีละส่วนสองครั้ง3. Transform of \(\sin at\) — integrating by parts twice

อินทิเกรตทีละส่วน (by parts)Integration by parts

จากกฎผลคูณ \(\dfrac{d(uv)}{dt} = u'v + uv'\) อินทิเกรตทั้งสองข้างได้

From the product rule \(\dfrac{d(uv)}{dt} = u'v + uv'\), integrating both sides gives

\[ uv = \int u'v + \int uv' \;\Longrightarrow\; \int u'v = uv - \int uv' \]
ตัวอย่าง 12.3Example 12.3\(f(t) = \sin at\)

รอบที่ 1: \(u' = e^{-st},\ u = -\tfrac1s e^{-st}\) และ \(v = \sin at,\ v' = a\cos at\)

First pass: \(u' = e^{-st},\ u = -\tfrac1s e^{-st}\) and \(v = \sin at,\ v' = a\cos at\).

\[ \int e^{-st}\sin at\,dt = -\tfrac1s e^{-st}\sin at + \tfrac{a}{s}\int e^{-st}\cos at\,dt \]

รอบที่ 2 กับ \(\int e^{-st}\cos at\,dt\): \(v = \cos at,\ v' = -a\sin at\)

Second pass on \(\int e^{-st}\cos at\,dt\): \(v = \cos at,\ v' = -a\sin at\).

\[ \int e^{-st}\cos at\,dt = -\tfrac1s e^{-st}\cos at - \tfrac{a}{s}\int e^{-st}\sin at\,dt \]

แทนกลับ — อินทิกรัลเดิม \(\mathcal{L}\{\sin at\}\) ปรากฏขึ้นอีกครั้งทางขวา:

Substitute back — the original integral \(\mathcal{L}\{\sin at\}\) reappears on the right:

\[ \mathcal{L}\{\sin at\} = \Big[-\tfrac1s e^{-st}\sin at - \tfrac{a}{s^2}e^{-st}\cos at\Big]_0^{\infty} - \frac{a^2}{s^2}\,\mathcal{L}\{\sin at\} \]

ย้ายข้าง แล้วประเมินค่าขอบ (ที่ \(t = \infty\) ได้ 0 เพราะ \(e^{-st} \to 0\); ที่ \(t = 0\) ได้ \(-\tfrac{a}{s^2}\)):

Move it to the left and evaluate the bracket (0 at \(t = \infty\) since \(e^{-st} \to 0\); \(-\tfrac{a}{s^2}\) at \(t = 0\)):

\[ \left(1 + \frac{a^2}{s^2}\right)\mathcal{L}\{\sin at\} = 0 - \left(-\frac{a}{s^2}\right) = \frac{a}{s^2} \;\Rightarrow\; \frac{s^2 + a^2}{s^2}\,\mathcal{L}\{\sin at\} = \frac{a}{s^2} \]
ผลลัพธ์Result\(\mathcal{L}\{\sin at\} = \dfrac{a}{s^2 + a^2}\)

4. ลาปลาซเป็นการดำเนินการเชิงเส้น4. Laplace is a linear operation

\[ \mathcal{L}\{c_1f(t) + c_2g(t)\} = \int_0^{\infty} e^{-st}\big[c_1f(t) + c_2g(t)\big]dt = c_1\int_0^{\infty} e^{-st}f(t)\,dt + c_2\int_0^{\infty} e^{-st}g(t)\,dt \]
ความเป็นเชิงเส้นLinearity
\[ \mathcal{L}\{c_1f + c_2g\} = c_1\,\mathcal{L}\{f\} + c_2\,\mathcal{L}\{g\} \]

ลาปลาซของฟังก์ชันที่บวกกัน = ลาปลาซแยกทีละฟังก์ชันแล้วนำมาบวกกัน (เงื่อนไขเดียวกับการแปลงเชิงเส้นในบทที่ 4)

The transform of a sum = the sum of the separate transforms (the same condition as linear transformations in Chapter 4).

5. ลาปลาซของอนุพันธ์5. Transforms of derivatives

ตัวอย่าง 12.4Example 12.4\(\mathcal{L}\{f'(t)\}\)

อินทิเกรตทีละส่วนในรูป \(\int uv' = uv - \int u'v\) โดย \(u = e^{-st},\ u' = -se^{-st}\) และ \(v' = f'(t),\ v = f(t)\):

Integrate by parts as \(\int uv' = uv - \int u'v\) with \(u = e^{-st},\ u' = -se^{-st}\) and \(v' = f'(t),\ v = f(t)\):

\[ \mathcal{L}\{f'\} = \Big[e^{-st}f(t)\Big]_0^{\infty} + s\underbrace{\int_0^{\infty} e^{-st}f(t)\,dt}_{\mathcal{L}\{f\}} = \big[0 - f(0)\big] + s\,\mathcal{L}\{f\} \]
ผลลัพธ์Result\(\mathcal{L}\{f'(t)\} = s\,\mathcal{L}\{f(t)\} - f(0)\)

ใช้สูตรนี้ซ้ำกับ \(f'\) จะได้อนุพันธ์อันดับสูงขึ้น:

Apply the same rule to \(f'\) to get higher derivatives:

\[ \mathcal{L}\{f''\} = s\,\mathcal{L}\{f'\} - f'(0) = s\big[s\,\mathcal{L}\{f\} - f(0)\big] - f'(0) = s^2\mathcal{L}\{f\} - sf(0) - f'(0) \]
ลาปลาซของอนุพันธ์ (เขียน \(Y = \mathcal{L}\{y\}\))Transforms of derivatives (write \(Y = \mathcal{L}\{y\}\))
\[ \begin{aligned} \mathcal{L}\{y'\} &= sY - y(0) \\ \mathcal{L}\{y''\} &= s^2Y - sy(0) - y'(0) \\ \mathcal{L}\{y''''\} &= s^4Y - s^3y(0) - s^2y'(0) - sy''(0) - y'''(0) \\ \mathcal{L}\{y^{(n)}\} &= s^nY - s^{n-1}y(0) - s^{n-2}y'(0) - \cdots - y^{(n-1)}(0) \end{aligned} \]

รูปแบบ: กำลังของ \(s\) ลดลงทีละหนึ่ง ขณะที่จำนวนครั้งของอนุพันธ์ของ \(y\) เพิ่มขึ้นทีละหนึ่ง

Pattern: the power of \(s\) goes down by one while the derivative order of \(y\) goes up by one.

6. \(\cos at\) และพหุนาม \(t^n\)6. \(\cos at\) and polynomials \(t^n\)

ตัวอย่าง 12.5Example 12.5\(\mathcal{L}\{\cos at\}\)

ไม่ต้องอินทิเกรตใหม่: \(\cos at\) เป็นอนุพันธ์ของ \(f(t) = \tfrac1a\sin at\) และ \(f(0) = 0\)

No new integral needed: \(\cos at\) is the derivative of \(f(t) = \tfrac1a\sin at\), and \(f(0) = 0\).

\[ \mathcal{L}\{\cos at\} = s\,\mathcal{L}\left\{\tfrac1a\sin at\right\} - \tfrac1a\sin 0 = \frac{s}{a}\cdot\frac{a}{s^2 + a^2} = \frac{s}{s^2 + a^2} \]
ผลลัพธ์Result\(\mathcal{L}\{\cos at\} = \dfrac{s}{s^2 + a^2}\)

จัดรูปสูตรอนุพันธ์ใหม่ เพื่อหาลาปลาซของ \(f\) จากลาปลาซของ \(f'\):

Rearrange the derivative rule to get the transform of \(f\) from that of \(f'\):

\[ \mathcal{L}\{f\} = \frac1s\Big[\mathcal{L}\{f'\} + f(0)\Big] \]
ตัวอย่าง 12.6Example 12.6\(t,\ t^2,\ t^3\)
\[ \begin{aligned} \mathcal{L}\{t\} &= \tfrac1s\big[\mathcal{L}\{1\} + 0\big] = \tfrac1s\cdot\tfrac1s = \frac{1}{s^2} \\ \mathcal{L}\{t^2\} &= \tfrac1s\big[\mathcal{L}\{2t\} + 0\big] = \tfrac1s\cdot\tfrac{2}{s^2} = \frac{2}{s^3} \\ \mathcal{L}\{t^3\} &= \tfrac1s\big[\mathcal{L}\{3t^2\} + 0\big] = \tfrac1s\cdot 3\cdot\tfrac{2}{s^3} = \frac{3\cdot2}{s^4} \end{aligned} \]
รูปทั่วไปGeneral form\(\mathcal{L}\{t^n\} = \dfrac{n!}{s^{n+1}}\)

7. ลาปลาซผกผันและเศษส่วนย่อย7. The inverse transform & partial fractions

การหา \(y\) จาก \(\mathcal{L}\{y\}\) เรียกว่า การแปลงลาปลาซผกผัน \(\mathcal{L}^{-1}\) — อ่านตารางย้อนกลับ เช่น \(\dfrac{1}{s - a} \to e^{at}\) ถ้าเศษส่วนซับซ้อน ให้แยกเป็นเศษส่วนย่อยก่อน (ย้อนกระบวนการ “รวมเศษส่วน” เช่น \(\tfrac23 + \tfrac57 = \tfrac{2(7) + 5(3)}{(3)(7)} = \tfrac{29}{21}\))

Finding \(y\) from \(\mathcal{L}\{y\}\) is the inverse Laplace transform \(\mathcal{L}^{-1}\): read the table backwards, e.g. \(\dfrac{1}{s - a} \to e^{at}\). If the fraction is complicated, first split it into partial fractions (the reverse of adding fractions, e.g. \(\tfrac23 + \tfrac57 = \tfrac{2(7) + 5(3)}{(3)(7)} = \tfrac{29}{21}\)).

ตัวอย่าง 12.7Example 12.7\(\mathcal{L}\{y\} = \dfrac{2s + 13}{s^2 + 5s + 6}\)
\[ \frac{2s + 13}{(s + 3)(s + 2)} = \frac{A}{s + 3} + \frac{B}{s + 2} = \frac{A(s + 2) + B(s + 3)}{(s + 3)(s + 2)} \]

เทียบสัมประสิทธิ์: \((A + B)s = 2s\) และ \(2A + 3B = 13\) จึงได้ \(A + B = 2\) → \(A = -7,\ B = 9\)

Match coefficients: \((A + B)s = 2s\) and \(2A + 3B = 13\), so \(A + B = 2\) → \(A = -7,\ B = 9\).

\[ \mathcal{L}\{y\} = -7\cdot\frac{1}{s - (-3)} + 9\cdot\frac{1}{s - (-2)} = -7\,\mathcal{L}\{e^{-3t}\} + 9\,\mathcal{L}\{e^{-2t}\} = \mathcal{L}\{9e^{-2t} - 7e^{-3t}\} \]
ผลลัพธ์Result\(y = 9e^{-2t} - 7e^{-3t}\)
ตัวอย่าง 12.8Example 12.8\(\mathcal{L}\{y\} = \dfrac{s - 1}{s^2 - s - 2}\)
\[ \frac{s - 1}{(s - 2)(s + 1)} = \frac{A}{s - 2} + \frac{B}{s + 1} \;\Rightarrow\; (A + B)s + (A - 2B) = s - 1 \]

\(A + B = 1,\ A - 2B = -1\) → \(A = \tfrac13,\ B = \tfrac23\)

\(A + B = 1,\ A - 2B = -1\) → \(A = \tfrac13,\ B = \tfrac23\).

\[ \mathcal{L}\{y\} = \frac13\cdot\frac{1}{s - 2} + \frac23\cdot\frac{1}{s - (-1)} \]
ผลลัพธ์Result\(y(t) = \tfrac13e^{2t} + \tfrac23e^{-t}\)

8. แก้สมการเชิงอนุพันธ์ด้วยลาปลาซ8. Solving differential equations with Laplace

ตัวอย่าง 12.9Example 12.9\(y'' + 5y' + 6y = 0,\ \ y(0) = 2,\ y'(0) = 3\)

ขั้นที่ 1: ลาปลาซทั้งสองข้าง (ใช้ความเป็นเชิงเส้น):

Step 1: take the Laplace transform of both sides (linearity):

\[ \mathcal{L}\{y''\} + 5\,\mathcal{L}\{y'\} + 6\,\mathcal{L}\{y\} = 0 \]
\[ \big[s^2Y - s\underbrace{y(0)}_{2} - \underbrace{y'(0)}_{3}\big] + 5\big[sY - \underbrace{y(0)}_{2}\big] + 6Y = 0 \]

ขั้นที่ 2: แก้หา \(Y\):

Step 2: solve for \(Y\):

\[ (s^2 + 5s + 6)\,Y - 2s - 3 - 10 = 0 \;\Rightarrow\; Y = \frac{2s + 13}{s^2 + 5s + 6} \]

ขั้นที่ 3: ลาปลาซผกผัน — คือตัวอย่าง 12.7 พอดี

Step 3: inverse transform — this is exactly Example 12.7.

PS\(y = 9e^{-2t} - 7e^{-3t}\)

ตรวจ: \(y(0) = 9 - 7 = 2\) ✓ และ \(y'(0) = -18 + 21 = 3\) ✓ — สมการเดียวกับตัวอย่าง 11.1 ในบทที่ 11 (รากลักษณะเฉพาะ \(-2, -3\)) แต่ลาปลาซหาผลเฉลยเฉพาะได้ในขั้นตอนเดียว

Check: \(y(0) = 9 - 7 = 2\) ✓ and \(y'(0) = -18 + 21 = 3\) ✓. It is the same equation as Example 11.1 in Chapter 11 (characteristic roots \(-2, -3\)), but Laplace delivers the particular solution in one pass.

9. ทฤษฎีบทการเลื่อน9. The shifting theorem

คูณ \(f(t)\) ด้วย \(e^{at}\) จะได้

Multiplying \(f(t)\) by \(e^{at}\) gives

\[ \mathcal{L}\{e^{at}f(t)\} = \int_0^{\infty} e^{-st}e^{at}f(t)\,dt = \int_0^{\infty} e^{-(s - a)t}f(t)\,dt \]

ซึ่งคือนิยามของ \(F(s)\) ที่แทน \(s\) ด้วย \(s - a\):

which is the definition of \(F(s)\) with \(s\) replaced by \(s - a\):

ทฤษฎีบทการเลื่อนShifting theorem
\[ \mathcal{L}\{e^{at}f(t)\} = F(s - a) \]
ตัวอย่าง 12.10Example 12.10\(\mathcal{L}\{e^{3t}\cos2t\}\)
\[ \mathcal{L}\{\cos2t\} = F(s) = \frac{s}{s^2 + 4} \;\Rightarrow\; \mathcal{L}\{e^{3t}\cos2t\} = F(s - 3) = \frac{s - 3}{(s - 3)^2 + 4} \]

10. ตารางการแปลงลาปลาซ10. Table of Laplace transforms
