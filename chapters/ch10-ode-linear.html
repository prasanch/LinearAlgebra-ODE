ODE 3: สมการเชิงเส้นอันดับหนึ่งODE 3: First-Order Linear Equations

สมการรูป \(\dfrac{dy}{dx} + P(x)\,y = Q(x)\) แก้ได้เสมอด้วยตัวประกอบอินทิเกรต \(\mu = e^{\int P(x)\,dx}\) ซึ่งเปลี่ยนด้านซ้ายให้เป็นอนุพันธ์ของผลคูณ \(\mu y\) แล้วอินทิเกรตได้ทันที

Equations of the form \(\dfrac{dy}{dx} + P(x)\,y = Q(x)\) can always be solved with the integrating factor \(\mu = e^{\int P(x)\,dx}\), which turns the left side into the derivative of the product \(\mu y\) so we can integrate directly.

1. รูปแบบมาตรฐาน1. Standard form

สมการเชิงเส้นอันดับหนึ่งFirst-order linear equation
\[ \frac{dy}{dx} + P(x)\,y = Q(x) \]

“เชิงเส้น” เพราะ \(y\) และ \(y'\) ปรากฏแค่ยกกำลังหนึ่ง และไม่คูณกันเอง — \(P(x)\) คือสัมประสิทธิ์ที่คูณกับ \(y\) ส่วน \(Q(x)\) คือพจน์อิสระ (ไม่มี \(y\))

It is “linear” because \(y\) and \(y'\) appear only to the first power and never multiply each other. \(P(x)\) is the coefficient multiplying \(y\); \(Q(x)\) is the free term (no \(y\)).

ขั้นแรกเสมอ: จัดรูปAlways first: rearrange

สัมประสิทธิ์หน้า \(\dfrac{dy}{dx}\) ต้องเป็น 1 ก่อนอ่านค่า \(P(x)\) และ \(Q(x)\) — ถ้าไม่ใช่ ให้หารตลอดทั้งสมการ เช่น \(3y' + 12y = 0 \Rightarrow y' + 4y = 0\) หรือ \(xy' + 2y = 3 \Rightarrow y' + \tfrac2x y = \tfrac3x\)

The coefficient of \(\dfrac{dy}{dx}\) must be 1 before you read off \(P(x)\) and \(Q(x)\). If it isn’t, divide the whole equation — e.g. \(3y' + 12y = 0 \Rightarrow y' + 4y = 0\), or \(xy' + 2y = 3 \Rightarrow y' + \tfrac2x y = \tfrac3x\).

2. ตัวประกอบอินทิเกรต \(\mu\)2. The integrating factor \(\mu\)

ขั้นตอน 3 ขั้นThree-step recipe
  1. จัดรูปให้เป็น \(y' + P(x)\,y = Q(x)\) แล้วระบุ \(P(x)\) และ \(Q(x)\)Rearrange to \(y' + P(x)\,y = Q(x)\) and identify \(P(x)\) and \(Q(x)\).
  2. หา \(\mu\):Find \(\mu\):
    \[ \mu = e^{\int P(x)\,dx} \]
  3. แทนค่า \(\mu\) ในสมการ แล้วอินทิเกรตทั้งสองข้าง:Substitute \(\mu\) and integrate both sides:
    \[ \frac{d(\mu y)}{dx} = \mu\,Q(x) \;\;\Longrightarrow\;\; \mu y = \int \mu\,Q(x)\,dx + C \]

ทำไมถึงได้ผลWhy it works

เพราะ \(\mu = e^{\int P\,dx}\) จะได้ \(\mu' = P\mu\) (กฎลูกโซ่) ดังนั้นตามกฎผลคูณ

Since \(\mu = e^{\int P\,dx}\), the chain rule gives \(\mu' = P\mu\). By the product rule,

\[ \frac{d(\mu y)}{dx} = \mu y' + \mu' y = \mu y' + \mu P y = \mu\big(y' + P y\big) = \mu\,Q \]

คือการคูณ \(\mu\) ทั้งสองข้างของสมการ ทำให้ด้านซ้าย “ยุบ” เป็นอนุพันธ์ของ \(\mu y\) พอดี

Multiplying the equation by \(\mu\) makes the left side collapse exactly into the derivative of \(\mu y\).

ค่าคงที่ในเลขชี้กำลังของ \(\mu\)The constant inside \(\mu\)

\(\int P\,dx\) มี \(+C\) แต่ \(e^{\,\cdots + C} = e^{\cdots}\cdot e^{C}\) และ \(e^{C}\) เป็นค่าคงที่ที่ตัดกันทั้งสองข้าง จึงไม่ต้องใส่ค่าคงที่ใน \(\mu\) — ใช้ \(C\) แค่ครั้งเดียวตอนอินทิเกรต \(\mu Q\)

\(\int P\,dx\) carries a \(+C\), but \(e^{\,\cdots + C} = e^{\cdots}\cdot e^{C}\) and \(e^{C}\) is a constant that cancels from both sides, so drop the constant in \(\mu\). The one \(C\) you need appears when integrating \(\mu Q\).

สูตรที่ใช้บ่อย: \(e^{\ln a} = a\) ดังนั้น \(e^{\int \frac2x dx} = e^{2\ln|x|} = e^{\ln x^2} = x^2\)

Handy identity: \(e^{\ln a} = a\), so \(e^{\int \frac2x dx} = e^{2\ln|x|} = e^{\ln x^2} = x^2\).

3. ตัวอย่างแรก3. A first example

ตัวอย่าง 10.1Example 10.1\(\dfrac{dy}{dx} + y = e^{3x}\)

ขั้นที่ 1: อยู่ในรูปแล้ว \(P(x) = 1,\ Q(x) = e^{3x}\)

Step 1: already in form, \(P(x) = 1,\ Q(x) = e^{3x}\).

ขั้นที่ 2:

Step 2:

\[ \mu = e^{\int 1\,dx} = e^{x} \]

ขั้นที่ 3:

Step 3:

\[ \frac{d(e^{x}y)}{dx} = e^{x}\cdot e^{3x} = e^{4x} \;\Rightarrow\; \int d(e^{x}y) = \int e^{4x}\,dx \]

ด้านขวาใช้ \(u = 4x,\ du = 4\,dx\): \(\int e^{4x}dx = \tfrac14\int e^{4x}\,d(4x) = \tfrac14 e^{4x}\)

For the right side use \(u = 4x,\ du = 4\,dx\): \(\int e^{4x}dx = \tfrac14\int e^{4x}\,d(4x) = \tfrac14 e^{4x}\).

\[ e^{x}y = \tfrac14 e^{4x} + C \;\Rightarrow\; y = \frac{\tfrac14 e^{4x}}{e^{x}} + \frac{C}{e^{x}} \]
GS\(y = \tfrac14 e^{3x} + Ce^{-x}\)

ตรวจ: \(y' = \tfrac34e^{3x} - Ce^{-x}\) ดังนั้น \(y' + y = e^{3x}\) ✓

Check: \(y' = \tfrac34e^{3x} - Ce^{-x}\), so \(y' + y = e^{3x}\) ✓

4. ทดลอง: ตระกูลของผลเฉลย4. Explore: the solution family

ผลเฉลยทั่วไป \(y = \tfrac14e^{3x} + Ce^{-x}\) คือตระกูลของเส้นโค้ง — แต่ละค่า \(C\) ให้หนึ่งเส้น เงื่อนไขเริ่มต้น \(y(0) = y_0\) เลือกเส้นเดียว (ผลเฉลยเฉพาะ) เพราะ \(y(0) = \tfrac14 + C\) จึงได้ \(C = y_0 - \tfrac14\)

The general solution \(y = \tfrac14e^{3x} + Ce^{-x}\) is a family of curves, one for each \(C\). An initial condition \(y(0) = y_0\) picks out one curve (the particular solution): since \(y(0) = \tfrac14 + C\), we get \(C = y_0 - \tfrac14\).

ทดลองInteractive\(y = \tfrac14e^{3x} + Ce^{-x}\)
ผลเฉลยทั่วไป (หลายค่า C)general solution (several C)ผลเฉลยเฉพาะที่ผ่าน (0, y₀)particular solution through (0, y₀)

5. กรณี \(Q(x) = 0\)5. The case \(Q(x) = 0\)

ถ้า \(Q = 0\) ขั้นที่ 3 ให้ \(\dfrac{d(\mu y)}{dx} = 0\) ดังนั้น \(\mu y = C\) หรือ \(y = C/\mu\) เสมอ (สมการเหล่านี้แยกตัวแปรได้ด้วย ใช้วิธีไหนก็ได้คำตอบเดียวกัน)

If \(Q = 0\), step 3 gives \(\dfrac{d(\mu y)}{dx} = 0\), so \(\mu y = C\), i.e. \(y = C/\mu\). (These equations are also separable — both methods give the same answer.)

ตัวอย่าง 10.2Example 10.2\(5y\,dx - dy = 0\)
\[ 5y\,dx = dy \;\Rightarrow\; \frac{dy}{dx} = 5y \;\Rightarrow\; \frac{dy}{dx} - 5y = 0,\qquad P(x) = -5,\ Q(x) = 0 \]
\[ \mu = e^{\int(-5)\,dx} = e^{-5x},\qquad \frac{d(e^{-5x}y)}{dx} = e^{-5x}\cdot 0 \;\Rightarrow\; e^{-5x}y = C \]
GS\(y = Ce^{5x}\)
ตัวอย่าง 10.3Example 10.3\(2y\,dx + dy = 0\)
\[ \frac{dy}{dx} + 2y = 0,\quad P = 2,\ Q = 0,\quad \mu = e^{\int 2\,dx} = e^{2x} \;\Rightarrow\; e^{2x}y = C \]
GS\(y = Ce^{-2x}\)
ตัวอย่าง 10.4Example 10.4\(3y' + 12y = 0,\ \ y(0) = 5\)

สัมประสิทธิ์หน้า \(y'\) คือ 3 ต้องหารด้วย 3 ก่อน:

The coefficient of \(y'\) is 3, so divide by 3 first:

\[ \frac{dy}{dx} + \tfrac{12}{3}\,y = 0 \;\Rightarrow\; \frac{dy}{dx} + 4y = 0,\quad \mu = e^{4x},\quad e^{4x}y = C \;\Rightarrow\; y = Ce^{-4x}\ \text{(GS)} \]

แทน \(y(0) = 5\): \(5 = Ce^{0} \Rightarrow C = 5\)

Apply \(y(0) = 5\): \(5 = Ce^{0} \Rightarrow C = 5\).

PS\(y = 5e^{-4x}\)

6. เมื่อ \(P\) ขึ้นกับ \(x\)6. When \(P\) depends on \(x\)

ตัวอย่าง 10.5Example 10.5\(xy' + 2y = 3\)

หารตลอดด้วย \(x\):

Divide through by \(x\):

\[ \frac{dy}{dx} + \frac2x\,y = \frac3x,\qquad P(x) = \frac2x,\ Q(x) = \frac3x \]
\[ \mu = e^{\int \frac2x dx} = e^{2\ln|x|} = e^{\ln x^2} = x^2 \]
\[ \frac{d(x^2y)}{dx} = x^2\cdot\frac3x = 3x \;\Rightarrow\; x^2y = \frac{3x^2}{2} + C \;\Rightarrow\; y = \frac32 + \frac{C}{x^2} \]
GS\(y = Cx^{-2} + \tfrac32\)
ตัวอย่าง 10.6Example 10.6\(\dfrac{dy}{dx} = y + e^{x}\)
\[ \frac{dy}{dx} + (-1)\,y = e^{x},\quad P = -1,\ Q = e^{x},\quad \mu = e^{-x} \]
\[ \frac{d(e^{-x}y)}{dx} = e^{-x}\cdot e^{x} = 1 \;\Rightarrow\; e^{-x}y = x + C \]
GS\(y = xe^{x} + Ce^{x}\)
ตัวอย่าง 10.7Example 10.7\(x^2y' + xy = 1\)

หารตลอดด้วย \(x^2\):

Divide through by \(x^2\):

\[ \frac{dy}{dx} + \frac{x}{x^2}\,y = \frac1{x^2} \;\Rightarrow\; P = \frac1x,\ Q = \frac1{x^2},\qquad \mu = e^{\ln|x|} = x \]
\[ \frac{d(xy)}{dx} = x\cdot\frac1{x^2} = \frac1x \;\Rightarrow\; xy = \ln|x| + C \]
GS\(y = \dfrac{\ln|x|}{x} + \dfrac{C}{x}\)
ตัวอย่าง 10.8Example 10.8\((x - x^3 + 4y)\,dx + x\,dy = 0\)
\[ x\frac{dy}{dx} = -x + x^3 - 4y \;\Rightarrow\; x\frac{dy}{dx} + 4y = x^3 - x \;\overset{\div x}{\Longrightarrow}\; \frac{dy}{dx} + \frac4x\,y = x^2 - 1 \]
\[ \mu = e^{\int\frac4x dx} = e^{4\ln|x|} = x^4,\qquad \frac{d(x^4y)}{dx} = x^4(x^2 - 1) = x^6 - x^4 \]
\[ x^4y = \frac{x^7}{7} - \frac{x^5}{5} + C \;\overset{\div x^4}{\Longrightarrow}\; y = \frac{x^3}{7} - \frac{x}{5} + \frac{C}{x^4} \]
GS\(y = \dfrac{x^3}{7} - \dfrac{x}{5} + Cx^{-4}\)

7. อินทิเกรตทีละส่วนแบบตาราง7. Tabular integration by parts

เมื่อ \(\mu Q\) เป็นพหุนามคูณเลขชี้กำลัง (เช่น \(e^{-2x}(x^2 + 5)\)) ใช้วิธีตาราง: หลัก D หาอนุพันธ์ของพหุนามซ้ำจนเป็น 0 หลัก I อินทิเกรตเลขชี้กำลังซ้ำ แล้วคูณทแยงลงพร้อมเครื่องหมายสลับ \(+,-,+,\dots\)

When \(\mu Q\) is a polynomial times an exponential (e.g. \(e^{-2x}(x^2 + 5)\)), use the tabular method: in column D differentiate the polynomial until it reaches 0, in column I integrate the exponential repeatedly, then multiply diagonally with alternating signs \(+,-,+,\dots\)

ตัวอย่าง 10.9Example 10.9\(y' = 2y + x^2 + 5\)
\[ \frac{dy}{dx} - 2y = x^2 + 5,\quad P = -2,\ Q = x^2 + 5,\quad \mu = e^{-2x} \]
\[ \frac{d(e^{-2x}y)}{dx} = e^{-2x}(x^2 + 5) \;\Rightarrow\; e^{-2x}y = \int e^{-2x}(x^2 + 5)\,dx \]
เครื่องหมายSignD (อนุพันธ์)D (differentiate)I (อินทิเกรต)I (integrate)
\(x^2 + 5\)\(e^{-2x}\)
\(+\)\(2x\)\(-\tfrac12e^{-2x}\)
\(-\)\(2\)\(\tfrac14e^{-2x}\)
\(+\)\(0\)\(-\tfrac18e^{-2x}\)
\[ e^{-2x}y = (x^2 + 5)\left(-\tfrac12e^{-2x}\right) - (2x)\left(\tfrac14e^{-2x}\right) + (2)\left(-\tfrac18e^{-2x}\right) + C \]

หารด้วย \(e^{-2x}\) (พจน์ \(C\) กลายเป็น \(Ce^{2x}\)):

Divide by \(e^{-2x}\) (the \(C\) term becomes \(Ce^{2x}\)):

GS\(y = -\tfrac12(x^2 + 5) - \tfrac12x - \tfrac14 + Ce^{2x} = -\tfrac12x^2 - \tfrac12x - \tfrac{11}{4} + Ce^{2x}\)

ตรวจ: \(y' = -x - \tfrac12 + 2Ce^{2x}\) และ \(2y + x^2 + 5 = -x - \tfrac12 + 2Ce^{2x}\) ✓

Check: \(y' = -x - \tfrac12 + 2Ce^{2x}\) and \(2y + x^2 + 5 = -x - \tfrac12 + 2Ce^{2x}\) ✓

8. เชิงเส้นใน \(x\): หา \(x(y)\)8. Linear in \(x\): solving for \(x(y)\)

บางสมการไม่เป็นเชิงเส้นใน \(y\) แต่เป็นเชิงเส้นใน \(x\) ถ้ามอง \(x\) เป็นฟังก์ชันของ \(y\) — สลับบทบาทได้เลย:

Some equations are not linear in \(y\) but are linear in \(x\) when \(x\) is treated as a function of \(y\). Just swap the roles:

รูปสลับSwapped form
\[ \frac{dx}{dy} + P(y)\,x = Q(y),\qquad \mu = e^{\int P(y)\,dy},\qquad \frac{d(\mu x)}{dy} = \mu\,Q(y) \]
ตัวอย่าง 10.10Example 10.10\(dx - (x + y)\,dy = 0\) — หา \(x\)\(dx - (x + y)\,dy = 0\) — find \(x\)
\[ \frac{dx}{dy} = x + y \;\Rightarrow\; \frac{dx}{dy} - x = y,\qquad P(y) = -1,\ Q(y) = y,\qquad \mu = e^{-y} \]
\[ \frac{d(e^{-y}x)}{dy} = ye^{-y} \;\Rightarrow\; e^{-y}x = \int ye^{-y}\,dy \]

วิธีตาราง: D: \(y \to 1 \to 0\) · I: \(e^{-y} \to -e^{-y} \to e^{-y}\)

Tabular method: D: \(y \to 1 \to 0\); I: \(e^{-y} \to -e^{-y} \to e^{-y}\).

\[ e^{-y}x = (y)(-e^{-y}) - (1)(e^{-y}) + C \;\overset{\div e^{-y}}{\Longrightarrow}\; x = -y - 1 + Ce^{y} \]
GS\(x = -y - 1 + Ce^{y}\)

Solve \(xy' - y = x^2\) (\(x > 0\)).

แก้ \(y' + y = x\) (ใช้วิธีตาราง)

\[ x = -2y - 2 + Ce^{y} \]
