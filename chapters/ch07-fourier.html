อนุกรมฟูเรียร์และการแปลงฟูเรียร์Fourier Series & the Fourier Transform

ฟังก์ชันเป็นคาบใด ๆ เขียนเป็นผลรวมของ \(\sin\) และ \(\cos\) ได้ (อนุกรมฟูเรียร์) และสัญญาณทั่วไปแปลงจาก “โดเมนเวลา” ไป “โดเมนความถี่” ได้ด้วยการแปลงฟูเรียร์ ซึ่งเป็นการแปลงเชิงเส้นแบบหนึ่ง และจะใช้ในการแก้สมการเชิงอนุพันธ์

Any periodic function can be written as a sum of sines and cosines (a Fourier series), and a general signal can be moved from the time domain to the frequency domain by the Fourier transform — itself a linear transformation, and a tool we will use for differential equations.

1. อนุกรมฟูเรียร์1. Fourier series

ฟังก์ชัน \(f(t)\) ที่มีคาบ \(2\pi\) เขียนเป็นผลรวมของค่าคงที่ โคไซน์ และไซน์ ที่ความถี่ \(n = 1, 2, 3, \dots\):

A function \(f(t)\) with period \(2\pi\) can be written as a constant plus cosines and sines of frequencies \(n = 1, 2, 3, \dots\):

อนุกรมฟูเรียร์ (คาบ \(2\pi\))Fourier series (period \(2\pi\))
\[ f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} a_n\cos nt + \sum_{n=1}^{\infty} b_n\sin nt \]
\[ a_0 = \frac1\pi\int_0^{2\pi} f(t)\,dt,\qquad a_n = \frac1\pi\int_0^{2\pi} f(t)\cos nt\,dt,\qquad b_n = \frac1\pi\int_0^{2\pi} f(t)\sin nt\,dt \]
คาบทั่วไป \(2L\)General period \(2L\)

ถ้าหนึ่งคาบยาว \(2L\) (เช่นช่วง \([-L, L]\)) ให้แทน \(nt\) ด้วย \(\dfrac{n\pi t}{L}\) และ \(\dfrac1\pi\int_0^{2\pi}\) ด้วย \(\dfrac1L\int_{-L}^{L}\):

If one period has length \(2L\) (e.g. the interval \([-L, L]\)), replace \(nt\) by \(\dfrac{n\pi t}{L}\) and \(\dfrac1\pi\int_0^{2\pi}\) by \(\dfrac1L\int_{-L}^{L}\):

\[ a_n = \frac1L\int_{-L}^{L} f(t)\cos\frac{n\pi t}{L}\,dt,\qquad b_n = \frac1L\int_{-L}^{L} f(t)\sin\frac{n\pi t}{L}\,dt \]

2. ตัวอย่าง: คลื่นสี่เหลี่ยม2. Example: a square wave

ตัวอย่าง 7.1Example 7.1
\[ f(t) = \begin{cases} 1, & 0 < t < \pi \\ 0, & \pi < t < 2\pi \end{cases}\qquad f(t + 2\pi) = f(t) \]

เพราะ \(f = 0\) บนช่วง \((\pi, 2\pi)\) อินทิกรัลเหลือแค่ช่วง \((0, \pi)\):

Since \(f = 0\) on \((\pi, 2\pi)\), only the interval \((0, \pi)\) contributes:

\[ a_0 = \frac1\pi\int_0^\pi 1\,dt = \frac1\pi\big[t\big]_0^\pi = 1 \]
\[ a_n = \frac1\pi\int_0^\pi \cos nt\,dt = \frac1\pi\left[\frac{\sin nt}{n}\right]_0^\pi = 0 \quad(\sin n\pi = 0) \]
\[ b_n = \frac1\pi\int_0^\pi \sin nt\,dt = \frac1\pi\left[-\frac{\cos nt}{n}\right]_0^\pi = \frac{1 - (-1)^n}{n\pi} = \begin{cases} \dfrac{2}{n\pi}, & n \text{ odd} \\[4pt] 0, & n \text{ even} \end{cases} \]

(เพราะ \(\cos n\pi = (-1)^n\): \(n = 1 \to \tfrac2\pi,\ n = 2 \to 0,\ n = 3 \to \tfrac{2}{3\pi}, \dots\))

(Using \(\cos n\pi = (-1)^n\): \(n = 1 \to \tfrac2\pi,\ n = 2 \to 0,\ n = 3 \to \tfrac{2}{3\pi}, \dots\))

คำตอบAnswer
\[ f(t) = \frac12 + \sum_{n\ \text{odd}} \frac{2}{n\pi}\sin nt = \frac12 + \frac2\pi\left(\sin t + \frac{\sin 3t}{3} + \frac{\sin 5t}{5} + \cdots\right) \]

4. การแปลงฟูเรียร์4. The Fourier transform

อนุกรมฟูเรียร์ใช้กับฟังก์ชันเป็นคาบ สำหรับสัญญาณทั่วไป (ไม่เป็นคาบ) เราใช้การแปลงฟูเรียร์ ซึ่งเป็น “กล่อง” ที่เปลี่ยน \(f(t)\) ในโดเมนเวลา เป็น \(F(\omega)\) ในโดเมนความถี่ — คล้ายการแปลงเชิงเส้น \(x \to \boxed{\ \ } \to y\) ในบทที่ 4

Fourier series handle periodic functions. For a general (non-periodic) signal we use the Fourier transform, a “box” that turns \(f(t)\) in the time domain into \(F(\omega)\) in the frequency domain — just like the transformation \(x \to \boxed{\ \ } \to y\) of Chapter 4.

การแปลงและการแปลงผกผันTransform and inverse
\[ F(\omega) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} f(t)\,e^{-i\omega t}\,dt \qquad\qquad f(t) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} F(\omega)\,e^{i\omega t}\,d\omega \]

\(\omega\) คือความถี่เชิงมุม บางตำราใช้ความถี่ปกติ \(\nu\) (\(\omega = 2\pi\nu\)) จะได้รูป \(F(\nu) = \int f(t)e^{-2\pi i\nu t}dt\) และ \(f(t) = \int F(\nu)e^{2\pi i\nu t}d\nu\) — เป็นเพียงการเลือกค่าคงที่ต่างกัน ความหมายเหมือนกัน

\(\omega\) is angular frequency. Some books use ordinary frequency \(\nu\) (\(\omega = 2\pi\nu\)), giving \(F(\nu) = \int f(t)e^{-2\pi i\nu t}dt\) and \(f(t) = \int F(\nu)e^{2\pi i\nu t}d\nu\). Only the constants differ; the meaning is the same.

สูตรของออยเลอร์Euler’s formula
\[ e^{i\theta} = \cos\theta + i\sin\theta,\qquad e^{-i\theta} = \cos\theta - i\sin\theta \;\;\Longrightarrow\;\; e^{i\theta} - e^{-i\theta} = 2i\sin\theta \]

5. ตัวอย่าง: พัลส์สี่เหลี่ยม5. Example: a rectangular pulse

ตัวอย่าง 7.2Example 7.2
\[ f(t) = \begin{cases} 1, & |t| < a \\ 0, & |t| > a \end{cases}\qquad F(\omega) = \,? \]

แบ่งอินทิกรัลเป็น 3 ช่วง ช่วง \((-\infty, -a)\) และ \((a, \infty)\) มี \(f = 0\):

Split the integral into three pieces; on \((-\infty, -a)\) and \((a, \infty)\) we have \(f = 0\):

\[ F(\omega) = \frac{1}{\sqrt{2\pi}}\int_{-a}^{a} e^{-i\omega t}\,dt = \frac{1}{\sqrt{2\pi}}\left[\frac{e^{-i\omega t}}{-i\omega}\right]_{-a}^{a} = \frac{e^{-i\omega a} - e^{i\omega a}}{-i\omega\sqrt{2\pi}} = \frac{e^{i\omega a} - e^{-i\omega a}}{i\omega\sqrt{2\pi}} \]

ใช้สูตรของออยเลอร์ \(e^{i\omega a} - e^{-i\omega a} = 2i\sin\omega a\):

With Euler’s formula, \(e^{i\omega a} - e^{-i\omega a} = 2i\sin\omega a\):

\[ F(\omega) = \frac{2i\sin\omega a}{i\omega\sqrt{2\pi}} = \sqrt{\frac{2}{\pi}}\;\frac{\sin \omega a}{\omega} \]

ที่ \(\omega = 0\) สูตรเป็น \(0/0\) จึงคำนวณจากนิยามโดยตรง (\(e^{0} = 1\)):

At \(\omega = 0\) the formula is \(0/0\), so go back to the definition (\(e^{0} = 1\)):

\[ F(0) = \frac{1}{\sqrt{2\pi}}\int_{-a}^{a} 1\,dt = \frac{2a}{\sqrt{2\pi}} = a\sqrt{\frac{2}{\pi}} \]

ซึ่งตรงกับลิมิต \(\lim_{\omega\to0}\frac{\sin\omega a}{\omega} = a\) กราฟของ \(F(\omega)\) เป็นรูป “sinc” มียอดที่ \(\omega = 0\) และตัดแกนครั้งแรกที่ \(\omega = \pm\pi/a\)

This matches the limit \(\lim_{\omega\to0}\frac{\sin\omega a}{\omega} = a\). The graph of \(F(\omega)\) is a “sinc” shape with its peak at \(\omega = 0\) and first zeros at \(\omega = \pm\pi/a\).

6. ทดลอง: ความกว้างของพัลส์ vs สเปกตรัม6. Explore: pulse width vs spectrum

เปลี่ยนค่า \(a\) แล้วสังเกต: พัลส์กว้างในเวลา → สเปกตรัมแคบและสูงในความถี่ และในทางกลับกัน (หลักความไม่แน่นอนของสัญญาณ)

Change \(a\) and watch: a pulse that is wide in time has a narrow, tall spectrum, and vice versa (the time–frequency uncertainty principle).

การแปลงฟูเรียร์เป็นเชิงเส้น: \(\mathcal F\{\alpha f + \beta g\} = \alpha\mathcal F\{f\} + \beta\mathcal F\{g\}\) และเปลี่ยนอนุพันธ์เป็นการคูณ (\(\mathcal F\{f'\} = i\omega F\)) จึงเปลี่ยน “สมการเชิงอนุพันธ์” เป็น “สมการพีชคณิต” — เราจะใช้แนวคิดนี้ (ผ่านการแปลงลาปลาซ) ในส่วน ODE

The Fourier transform is linear: \(\mathcal F\{\alpha f + \beta g\} = \alpha\mathcal F\{f\} + \beta\mathcal F\{g\}\). It also turns derivatives into multiplication (\(\mathcal F\{f'\} = i\omega F\)), converting differential equations into algebraic ones — an idea we use (through the Laplace transform) in the ODE part.
