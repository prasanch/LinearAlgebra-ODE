ODE 4: สมการเชิงอนุพันธ์อันดับสูงและการประยุกต์ODE 4: Higher-Order Equations & Applications

สมการเชิงเส้นอันดับสองที่มีสัมประสิทธิ์คงที่ \(Ay'' + By' + Cy = 0\) แก้ได้โดยเดาคำตอบรูป \(y = e^{rx}\) ซึ่งเปลี่ยนสมการเชิงอนุพันธ์ให้เป็นสมการพหุนาม \(Ar^2 + Br + C = 0\) — ชนิดของรากบอกรูปของคำตอบ วิธีเดียวกันใช้กับอันดับสามขึ้นไป และปิดท้ายด้วยแบบจำลองการเติบโต/การสลาย

Second-order linear equations with constant coefficients, \(Ay'' + By' + Cy = 0\), are solved by guessing \(y = e^{rx}\), which turns the differential equation into the polynomial \(Ar^2 + Br + C = 0\). The kind of roots decides the form of the solution. The same method works for third and higher order, and we finish with growth/decay models.

1. สมการเชิงอนุพันธ์อันดับสอง1. Second-order differential equations

ทบทวน: ODE อันดับหนึ่งที่เรียนมาแล้วมี 4 แบบ คือ แยกตัวแปรได้ เอกพันธ์ แม่นตรง และเชิงเส้น \(y' + P(x)y = Q(x)\) — คำว่า “เชิงเส้น” มาจาก \(y = mx + c\): \(y\) และอนุพันธ์ของมันปรากฏแค่ยกกำลังหนึ่ง (ต่างจาก \(\alpha y^2 + \beta y = Q(x)\) ซึ่งเป็นสมการกำลังสอง)

Recap: we have four first-order types — separable, homogeneous, exact and linear \(y' + P(x)y = Q(x)\). “Linear” comes from \(y = mx + c\): \(y\) and its derivatives appear only to the first power (unlike \(\alpha y^2 + \beta y = Q(x)\), which is quadratic).

สมการเชิงเส้นอันดับสองSecond-order linear equation
\[ a(x)\,y'' + b(x)\,y' + c(x)\,y = d(x) \]

อนุพันธ์ครั้งสูงสุดคือ 2 บทนี้ศึกษากรณีสัมประสิทธิ์คงที่และด้านขวาเป็นศูนย์:

The highest derivative is 2. This chapter studies constant coefficients with a zero right-hand side:

\[ Ay'' + By' + Cy = 0 \]
คำว่า “เอกพันธ์” มีสองความหมาย“Homogeneous” has two meanings

ในบทนี้ “เอกพันธ์” หมายถึงด้านขวาเท่ากับ 0 (\(d(x) = 0\)) ซึ่งคนละความหมายกับสมการเอกพันธ์ \(y' = F(y/x)\) ในบทที่ 9

Here “homogeneous” means the right-hand side is 0 (\(d(x) = 0\)). This is a different meaning from the homogeneous equations \(y' = F(y/x)\) of Chapter 9.

2. หลักการซ้อนทับ2. The superposition principle

ก่อนจะหาคำตอบ มาดูสมบัติสำคัญสองข้อของ \(Ay'' + By' + Cy = 0\):

Before solving, two key properties of \(Ay'' + By' + Cy = 0\):

(1) คูณค่าคงที่ได้(1) Constant multiples

ถ้า \(g(x)\) เป็นคำตอบ แล้ว \(C_1g(x)\) เป็นคำตอบด้วย:

If \(g(x)\) is a solution, so is \(C_1g(x)\):

\[ AC_1g'' + BC_1g' + CC_1g = C_1\underbrace{\big[Ag'' + Bg' + Cg\big]}_{=\,0} = 0 \]

(2) บวกกันได้(2) Sums

ถ้า \(g(x)\) และ \(h(x)\) เป็นคำตอบ แล้ว \(g + h\) เป็นคำตอบด้วย:

If \(g(x)\) and \(h(x)\) are solutions, so is \(g + h\):

\[ \underbrace{\big[Ag'' + Bg' + Cg\big]}_{=\,0} + \underbrace{\big[Ah'' + Bh' + Ch\big]}_{=\,0} = 0 \]
สรุปConclusion

ถ้า \(y_1\) และ \(y_2\) เป็นคำตอบ แล้ว \(y = C_1y_1 + C_2y_2\) ก็เป็นคำตอบ — นี่คือความเป็นเชิงเส้นแบบเดียวกับบทที่ 4 สมการอันดับสองต้องการคำตอบอิสระ 2 ตัว (และค่าคงที่ 2 ตัว) ในผลเฉลยทั่วไป

If \(y_1\) and \(y_2\) are solutions, then \(y = C_1y_1 + C_2y_2\) is too — the same linearity as in Chapter 4. A second-order equation needs two independent solutions (and two constants) in its general solution.

3. สมการลักษณะเฉพาะ3. The characteristic equation

ตัวอย่าง 11.1Example 11.1\(y'' + 5y' + 6y = 0\)

สมมติให้คำตอบมีรูป \(y = e^{rx}\) จะได้ \(y' = re^{rx}\) และ \(y'' = r^2e^{rx}\) แทนค่าในสมการ:

Assume a solution of the form \(y = e^{rx}\). Then \(y' = re^{rx}\) and \(y'' = r^2e^{rx}\). Substitute:

\[ r^2e^{rx} + 5re^{rx} + 6e^{rx} = 0 \;\Rightarrow\; e^{rx}\big[r^2 + 5r + 6\big] = 0 \]

\(e^{rx}\) เป็น 0 ไม่ได้ ดังนั้น \(r^2 + 5r + 6 = 0\) → \((r+2)(r+3) = 0\) → \(r = -2, -3\) ได้คำตอบสองตัว \(y_1 = e^{-2x},\ y_2 = e^{-3x}\)

\(e^{rx}\) is never 0, so \(r^2 + 5r + 6 = 0\) → \((r+2)(r+3) = 0\) → \(r = -2, -3\), giving two solutions \(y_1 = e^{-2x},\ y_2 = e^{-3x}\).

GS\(y(x) = C_1e^{-2x} + C_2e^{-3x}\)
ทางลัดShortcut

เปลี่ยน \(y^{(n)}\) (อนุพันธ์ครั้งที่ \(n\)) เป็น \(r^{n}\) ได้เลย: \(y'' \to r^2,\ y' \to r,\ y \to 1\)

Replace \(y^{(n)}\) (the \(n\)-th derivative) by \(r^{n}\) directly: \(y'' \to r^2,\ y' \to r,\ y \to 1\).

\[ Ay'' + By' + Cy = 0 \;\;\longrightarrow\;\; Ar^2 + Br + C = 0,\qquad r = \frac{-B \pm \sqrt{B^2 - 4AC}}{2A} \]

Case 3: by Euler’s formula (Chapter 7), \(e^{(\alpha + \beta i)x} = e^{\alpha x}(\cos\beta x + i\sin\beta x)\); its real and imaginary parts give two real solutions, \(e^{\alpha x}\cos\beta x\) and \(e^{\alpha x}\sin\beta x\).

9. การประยุกต์: การเติบโตและการสลาย9. Applications: growth & decay

สมการเชิงอนุพันธ์อธิบายอัตราการเปลี่ยนแปลง — อัตราการเติบโต (เพิ่มขึ้น) หรืออัตราการสลาย (ลดลง) ตัวอย่างเช่น

Differential equations describe rates of change — rates of growth (increasing) or decay (decreasing). Examples:

  • การสลายของสารกัมมันตรังสีradioactive decay
  • ประชากรศาสตร์population dynamics
  • การเพิ่มขึ้น/ลดลงของเชื้อโรคgrowth/decline of bacteria
แบบจำลองThe model

“อัตราการลดลง/เพิ่มขึ้นขึ้นอยู่กับจำนวนประชากร” — อัตราแปรผันตรงกับขนาด:

“The rate of decrease/increase depends on the population” — the rate is proportional to the size:

\[ \frac{dP}{dt} \propto P \;\Longrightarrow\; \frac{dP}{dt} = kP,\qquad P(t_0) = P_0 \]

เป็นสมการอันดับหนึ่งที่แยกตัวแปรได้ (หรือเชิงเส้น หรือใช้สมการลักษณะเฉพาะ \(r = k\)) ผลเฉลยคือ

This is first order and separable (or linear, or use the characteristic equation \(r = k\)). Its solution is

\[ P(t) = P_0\,e^{k(t - t_0)} \]

\(k > 0\): เติบโต · \(k < 0\): สลาย

\(k > 0\): growth; \(k < 0\): decay.

ตัวอย่าง 11.9Example 11.9ครึ่งชีวิตของคาร์บอน-14Half-life of carbon-14

คาร์บอน-14 มีครึ่งชีวิต 5730 ปี (เหลือครึ่งหนึ่งทุก 5730 ปี) ถ้าซากฟอสซิลเหลือ C-14 อยู่ 25% ของเดิม มีอายุเท่าไร?

Carbon-14 has a half-life of 5730 years (half remains after every 5730 years). If a fossil has 25% of its original C-14 left, how old is it?

\[ \tfrac12P_0 = P_0e^{k\cdot5730} \;\Rightarrow\; k = -\frac{\ln2}{5730} \approx -1.21\times10^{-4}\ \text{yr}^{-1} \]
\[ 0.25P_0 = P_0e^{kt} \;\Rightarrow\; t = \frac{\ln0.25}{k} = \frac{-2\ln2}{-\ln2/5730} = 2 \times 5730 = 11{,}460 \]
คำตอบAnswerประมาณ 11,460 ปี (สองครึ่งชีวิต: 100% → 50% → 25%)about 11,460 years (two half-lives: 100% → 50% → 25%)

แบคทีเรียมี 500 ตัวเมื่อ \(t = 0\) และเพิ่มเป็น 1500 ตัวเมื่อ \(t = 2\) ชั่วโมง (แบบจำลอง \(dP/dt = kP\)) จงหา \(k\) และจำนวนเมื่อ \(t = 4\)

A culture has 500 bacteria at \(t = 0\) and 1500 at \(t = 2\) hours (model \(dP/dt = kP\)). Find \(k\) and the count at \(t = 4\).

ดูเฉลยShow solution
\[ 1500 = 500e^{2k} \Rightarrow k = \tfrac12\ln3 \approx 0.549;\qquad P(4) = 500e^{4k} = 500\cdot 3^2 = 4500 \]
